# Project Overview

NEON NEXUS is an entertainment and creative hub designed to provide young people with a safe and engaging environment for entertainment, creativity, social interaction, and community development.

The purpose of this website is to provide visitors with information about the facilities, services, events, membership opportunities, and entertainment experiences available at NEON NEXUS.

The website uses HTML and CSS to create a visually engaging interface with a neon-inspired design. The website also includes responsive layouts so that the content can adapt to different screen sizes.

---

## Purpose of the Website

The purpose of NEON NEXUS is to provide users with information about an entertainment venue and its different experiences and services.

The website allows users to:

- Learn more about NEON NEXUS.
- Explore entertainment experiences.
- View upcoming events.
- Learn about membership options.
- Explore the NEXUS Cafe.
- View images through the gallery.
- Find contact information.
- Navigate between the different pages of the website.

## Responsive Design

Responsive design was implemented so that the website can adapt to different screen sizes.

CSS media queries are used to change elements such as:

- Page layouts.
- Content widths.
- Typography sizes.
- Navigation layouts.
- Spacing.
- Images.
- Cards and other content sections.

The website was tested using Google Chrome Developer Tools at different viewport sizes to check that the layout adapts correctly.

---

## Responsive Typography

Typography is adjusted at different screen sizes using CSS media queries.

This prevents headings, paragraphs and other text from becoming too large or too small on smaller screens.

The responsive typography also helps maintain readability and prevents text from overflowing outside of its intended layout.

---

## Responsive Navigation

The navigation layout is adjusted at smaller screen sizes using CSS.

This allows the navigation links to remain usable when the available screen width becomes smaller.

The navigation was tested using different viewport sizes in Google Chrome Developer Tools.

---

## Responsive Images

Images are used throughout the NEON NEXUS website to support the visual design and provide information about the different experiences.

Images are controlled using CSS so that they can resize within their containers without breaking the page layout.

Further responsive image implementation using appropriate HTML image techniques will be included where required by the project specification.

---

The website uses CSS pseudo-classes to provide visual interaction.

Examples include hover effects on:

These effects provide visual feedback when the user interacts with different elements of the website.
